# BitsAndSecret

Браузерная версия Bits & Bops для запуска на ПК.

[Открыть игру](https://demosand.github.io/BitsAndSecret/)

Нажмите «Играть» и дождитесь загрузки около 603 МБ данных. Управление: стрелки и Enter в меню, Space и кнопки, показанные в самой игре, во время уровней. Для звука и управления нажмите на игровое окно.

Прогресс хранится локально в браузере; дополнительно он записывается каждые 30 секунд и при уходе со страницы. Кнопка «Скачать сохранение» создаёт резервную копию, «Загрузить сохранение» позволяет её восстановить. После импорта обновите страницу. Сохранения разных браузеров и устройств независимы.

Сайт работает без серверной части. GitHub Actions публикует содержимое `site/` в GitHub Pages при изменении ветки `main`. Большие файлы игры разделены на части; загрузчик объединяет их при запуске. После первой загрузки браузер кэширует данные.

Репозиторий содержит готовую браузерную сборку. Инструменты Unity, профили входа, оригинальная установка и личные сохранения в него не включены.

Браузерная адаптация использует Unity Audio вместо нативного Tempo Engine. Для двух MIDI-режимов используется собственный секвенсор и банк записанных инструментов; их звучание и поведение могут отличаться от настольного синтезатора. Восстановленные эффекты искажения и стереографической проекции также могут отличаться от оригинала. Интеграция со Steam и Windows-диктором недоступна.

Параметры аудиоустройства и DSP-буфера определяет браузер. Вместо открытия папки пользовательского микстейпа скачивается его `.bop`-архив.
